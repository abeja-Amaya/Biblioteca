# Mi biblioteca

Proyecto pequeño para practicar Git y GitHub.

## Objetivo
Mostrar una lista sencilla de libros disponibles.

## Archivos principales
- `index.html`: estructura de la página.
- `estilos.css`: apariencia visual.
- `app.js`: interacción con la página.
- `libros.json`: datos de ejemplo.
- `Libro.java`: clase básica de un libro.

## Práctica
1. Crea un repositorio.
2. Agrega estos archivos.
3. Realiza un primer commit.
4. Modifica un archivo y crea otro commit.
5. Sube los cambios a GitHub.
